### Actionable findings
1. **Audience is the GC, not the tenant.** Every serious reference speaks to general contractors, developers and owners (bids, schedule, coordination). Local Plumbing's current industry pages speak to the end user in an emergency ("Clogged floor sink?"). A mixed-use page needs both: construction for GCs/developers, 24/7 service for property managers after turnover.
2. **Case-study format that wins:** metadata block (type, GC, location, period) + stat strip (units, floors, SF) + scope → challenge → outcome. Local Plumbing has one qualifying project (Nomad Building) that can use this format.
3. **Vocabulary to use where verified:** risers, stacks and vents, domestic water booster pumps, premise isolation (RPBA), recirculating hot water, tenant improvement rough-in, trim-out, grease waste for ground-floor food tenants.

### Differentiation gaps no reference owns
- **Construction *and* lifecycle service from one firm.** All Miami competitors sell either build (Detail, ARDOK, MCI, D'Plumbers) or coordination (BIMWERX). None sells "we built it, and we'll be on call 24/7 for the property manager after turnover." Local Plumbing's verified mix (new construction + TI + 24/7 + HVAC/boilers) fits this exactly.
- **Retail-tenant TI inside an occupied residential building** (noise, shutdowns, water outages to residents) — not covered anywhere.
- **Prequalification content** (license numbers, bonding, insurance, references) — nobody shows it.
- **Bid process clarity** (what to send, turnaround) — nobody explains it.
